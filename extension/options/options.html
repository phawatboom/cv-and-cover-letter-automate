Cover Letter Copilot

Settings stay in this browser. Drafting and résumé import send the required text through your local server to your configured model provider; the API key stays in the server.

Import résumé

PDF, DOCX, TXT, or MD; maximum 8 MB. The local server extracts its text, then sends that text to your configured model provider to suggest profile fields. Nothing is saved or placed into a job application until you review and approve it.

Backup

Chrome ties this extension's storage to the folder you loaded it from, so moving or renaming the project folder loses these settings. Keep an exported copy somewhere outside the project and importing it back is a ten-second job. The file holds your personal details and résumé in plain text — it does not contain your API key, which lives in server/.env.
